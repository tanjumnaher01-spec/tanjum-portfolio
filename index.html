LEAD CASE STUDY

BSc THESIS • DEEPFAKE DETECTION

Deepfake Detection

Comparing CNN models to understand how well deepfake detection can generalize across datasets.

The problem

Deepfake detection tools need to generalize beyond a single dataset. A model can perform well on the data it was trained and tested on, but that does not automatically mean it will work equally well when the data changes.

What I did

I compared seven CNN models across two datasets and evaluated their performance to understand how different architectures behave in deepfake detection.

What came of it

The research became my BSc thesis. I successfully defended the thesis and received an A+.

Next work: Dataset analysis is planned as a future part of the research. It is not presented here as completed work.

EARLIER PROJECT

FIRST AI PROJECT • KAGGLE

Weather Prediction: Bangladesh's 6 Seasons

An early project that taught me how data assumptions can limit an AI model before the algorithm becomes the main problem.

The problem

Many weather prediction approaches are built around four seasons, while Bangladesh is commonly described through six seasons. That difference can create a mismatch between the data and the problem being modeled.

What I did

I worked with a Kaggle dataset and built my first AI project. The project helped me understand how dataset structure, assumptions, and model design are connected.

What came of it

The model achieved 74% accuracy. More importantly, I learned that improving an AI system is not always about choosing a more complicated algorithm. Sometimes the data itself defines the ceiling.
